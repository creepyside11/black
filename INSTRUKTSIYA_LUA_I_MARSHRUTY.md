# Как установить Lua-загрузчик, запустить бота и смотреть логи

Эта инструкция для Android с Termux. Она относится именно к архиву `black_lua_loader.zip`.
В папке установки также есть более подробный `LUA_GUIDE_RU.md`.

## 1. Что внутри

- Сама программа `black` с Lua-загрузчиком.
- Примеры Lua-бота и дополнений в `scripts/lua/`.
- Контроллер маршрутов и файлы маршрутов в `scripts/routes/`.
- Журнал Lua и маршрутов в `logs/lua/`.
- Эта инструкция.

Архив — отдельная сборка. Он не переносит автоматически аккаунты и настройки из другой установки.
Не вводите пароль в Lua-файлы и не отправляйте другим папку с аккаунтами или полные логи.

## 2. Установка в Termux

Скачайте архив в папку «Загрузки» телефона, затем в Termux выполните по одной команде:

```sh
pkg update
pkg install python lua54 unzip nano -y
termux-setup-storage
```

Подтвердите доступ к файлам, если Android спросит. Затем:

```sh
mkdir -p "$HOME/black-routes"
unzip -o "$HOME/storage/downloads/black_lua_loader.zip" -d "$HOME/black-routes"
cd "$HOME/black-routes/black-lua-loader"
python bot.py
```

Если файл называется иначе, подставьте его фактическое имя. При первом запуске выберите `0`, чтобы перейти в консоль команд.

Создайте аккаунт в программе локально:

```text
/add СЕРВЕР НИК ПАРОЛЬ
/list
```

Вместо слов укажите данные своего аккаунта. Команда `/list` может показывать чувствительные данные, поэтому не публикуйте её вывод.
Узнайте числовой ID своего аккаунта. В примерах ниже ID равен `1`: замените его, если у вас другой.

## 3. Куда положить скачанный Lua-скрипт

Сценарии лежат в папке `scripts/lua/`. Допустим, вы скачали файл `my_bot.lua` в «Загрузки».
Откройте новую сессию Termux или выйдите из программы командой `/q`, затем выполните:

```sh
cd "$HOME/black-routes/black-lua-loader"
cp "$HOME/storage/downloads/my_bot.lua" scripts/lua/my_bot.lua
python bot.py
```

Команды `cd`, `cp` и `python` вводятся в оболочке Termux. Команды ниже, начинающиеся с `/lua`, вводятся уже в консоли самой программы.

В программе:

```text
/lua list
```

Проверьте, что `my_bot.lua` появился в списке. Имя файла должно заканчиваться на `.lua`, не на `.txt` или `.lua.txt`.
Не запускайте неизвестные Lua-скрипты от посторонних без проверки: ограничения загрузчика не являются полной гарантией безопасности.

## 4. Как запустить дополнение

Дополнение работает рядом с аккаунтом, но не подключает его само.

1. Запустите аккаунт командой `/start 1`.
2. Дождитесь подключения.
3. Проверьте дополнение в холостом режиме:

```text
/lua addon 1 hello_addon.lua --dry
/lua status 1
```

4. Чтобы остановить дополнение: `/lua stop 1`.
5. Для настоящего запуска уберите `--dry`:

```text
/lua addon 1 hello_addon.lua
```

Вместо `hello_addon.lua` можно указать имя своего файла. Действия Lua без `--dry` могут изменять состояние аккаунта.
`--dry` блокирует изменяющие действия Lua, но не останавливает уже запущенные Python-задачи.
Если дополнение и основная задача одновременно управляют движением или одним интерфейсом, они могут мешать друг другу. Остановите конфликтующую задачу.

## 5. Как запустить самостоятельного Lua-бота до спавна

Сначала остановите аккаунт, если он запущен:

```text
/stop 1
/lua bot 1 spawn_bot.lua --dry
/lua status 1
```

Режим `bot` запускает Lua до подключения аккаунта, затем программа подключает аккаунт. Даже с `--dry` подключение может начаться; сам выбор спавна и другие изменяющие действия Lua в холостом режиме не отправляются.

Для обычного запуска:

```text
/stop 1
/lua stop 1
/lua bot 1 spawn_bot.lua
```

Пример `spawn_bot.lua` ожидает меню и выбирает первый доступный числовой ID. Это не гарантия выбора нужного места или полностью готовой работы на шахте.
В режиме `bot` стандартная авторизация остаётся в Python, а спавном и соответствующими игровыми интерфейсами должен управлять сценарий.

Чтобы остановить только Lua: `/lua stop 1`. Чтобы остановить и аккаунт: `/stop 1`.
Для перезагрузки standalone-скрипта сначала остановите аккаунт, затем Lua и запустите сценарий заново.

## 6. Как запустить проверку маршрута

В архиве есть `route_addon_example.lua`, который использует `scripts/routes/example.json`.
Его координаты ВЫМЫШЛЕННЫЕ. Сначала проверьте только загрузку файла:

```text
/lua addon 1 route_addon_example.lua --dry
/lua status 1
```

В логе появится число точек. Бот не будет двигаться, а событие `on_route_dry` не означает, что точки проходимы.
Для реального движения необходимо заменить пример своими точками, остановить Lua и запустить дополнение без `--dry`.

## 7. Свой маршрут

Файлы маршрутов находятся в `scripts/routes/`. Имена состоят из латинских букв, цифр, `_` и `-`, например `my_route.json`.
В Termux:

```sh
cd "$HOME/black-routes/black-lua-loader"
nano scripts/routes/my_route.json
```

Содержимое — пример структуры; координаты нужно заменить своими:

```json
{
  "points": [
    {"x": 100.0, "y": 200.0, "z": 15.0, "radius": 2.0, "wait": 0},
    {"x": 120.0, "y": 230.0, "z": 15.0, "radius": 2.0, "wait": 3}
  ]
}
```

`radius` — радиус окончания движения контроллером, от 0.1 до 100. По умолчанию 2.
`wait` — пауза после точки в секундах, от 0 до 3600. По умолчанию 0.
Можно использовать и короткую форму точки: `[100.0, 200.0, 15.0]`.
В `nano` сохраните файл через `Ctrl+O`, Enter, выйдите через `Ctrl+X`. На телефоне `Ctrl` доступен в дополнительной панели клавиш Termux.

Создайте `scripts/lua/my_route.lua`:

```lua
function on_load(e)
  br.route_start('my_route', 'walk', {
    timeout = 120,
    stuck_timeout = 30
  })
end

function on_route_point(e)
  br.log(('Точка %d из %d пройдена'):format(e.point, e.total))
end

function on_route_end(e)
  br.log('Маршрут закончен контроллером движения')
end

function on_route_error(e)
  br.log('Маршрут остановился: ' .. tostring(e.reason))
end
```

В консоли программы после подключения аккаунта:

```text
/lua addon 1 my_route.lua --dry
/lua stop 1
/lua addon 1 my_route.lua
```

`walk` — пешком; `drive` — транспортом. Для `drive` самостоятельно убедитесь, что персонаж действительно сел в подходящий транспорт.
`timeout` — максимум секунд на одну точку. `stuck_timeout` — сколько секунд допустимо отсутствие заметного движения; оба параметра от 1 до 3600.
Небольшие колебания координат и серверные задержки могут вызвать ложное определение застревания; подбирайте параметры на практике.
Контроллер выдаёт `on_route_point` после статуса `arrived` от механизма движения проекта. Это не отдельное подтверждение сервера.
Если на точке требуется действие, задайте `wait` и обработайте событие `on_route_point`; не предполагается автоматическое определение NPC или игровых действий.

## 9. Остановка, пауза и события из Lua

- `br.route_start('my_route', 'walk', {timeout=120, stuck_timeout=30})` — начать.
- `br.route_pause()` — остановить текущее движение маршрута и поставить маршрут на паузу.
- `br.route_resume()` — продолжить с текущей точки; ожидание между точками после паузы может быть пропущено.
- `br.route_stop()` — прекратить маршрут.
- `br.route_status()` — снимок состояния на начало текущего обработчика.
- `on_route_start_point(e)` — начато движение к точке.
- `on_route_point(e)` — контроллер сообщает о достижении точки; поля `point`, `total`, `x`, `y`, `z`.
- `on_route_end(e)` — маршрут пройден по данным контроллера.
- `on_route_error(e)` — ошибка; поле `reason` описывает причину.
- `on_route_dry(e)` — файл проверен в холостом режиме.

Эти функции ставят команды в очередь: вызов функции Lua сам по себе не подтверждает выполнение. Если скрипт остановлен, движение маршрута отменяется.
При замене текущего движения другим контроллером маршрут завершится ошибкой, а не сочтёт точку пройденной.

### Сохранение маршрута из Lua

```lua
-- Вымышленные координаты: замените своими.
br.route_save('my_route', {
  {x=100, y=200, z=15, radius=2, wait=0},
  {x=120, y=230, z=15, radius=2, wait=3}
})
```

`br.route_save` сохраняет или заменяет одноимённый файл в `scripts/routes/` после проверки точек. Существующий файл с тем же именем будет перезаписан.
В `--dry` файл не записывается. Функция не записывает путь игрока автоматически — координаты нужно предоставить в таблице либо подготовить JSON вручную.
Загрузка и старт осуществляются через `br.route_start`. Возможны файлы маршрутов из 1–10000 точек; для больших маршрутов удобнее внешний JSON-файл.

## 10. Где смотреть логи

В Termux после выхода из программы или в отдельной сессии:

```sh
cd "$HOME/black-routes/black-lua-loader"
ls logs/lua
cat logs/lua/account_1.log
```

Для просмотра обновлений в реальном времени:

```sh
tail -f logs/lua/account_1.log
```

Остановить просмотр `tail`: `Ctrl+C`. Замените `1` на ID нужного аккаунта.
В журнале есть время телефона, имя скрипта и сообщения маршрута: номер точки, начало, прибытие и причина остановки.
Файлы ограничены примерно 1 МБ каждый; сохраняются до трёх предыдущих файлов.
Это журнал Lua и контроллера маршрутов, а не полная запись каждого сетевого пакета или всех действий Python-бота.
Часть паролей и токенов в виде `ключ=значение` скрывается, но автоматическая очистка неполная: перед передачей логов проверьте их вручную.
Самостоятельно не выводите пароли, токены, содержимое капчи, приватные сообщения и сырые пакеты через `br.log`.

## 11. Частые вопросы

**`Lua не найден`** — установите `pkg install lua54`, проверьте `lua5.4 -v`, `lua54 -v` или `lua -v`; при необходимости задайте `BR_LUA_BIN`.

**Скрипта нет в `/lua list`** — проверьте расположение в `scripts/lua`, имя и расширение `.lua`.

**`bot` не запускается** — сначала остановите аккаунт через `/stop 1` и предыдущий Lua через `/lua stop 1`.

**Маршрут не двигается** — проверьте подключение, правильный аккаунт и отсутствие `--dry`. Посмотрите `account_1.log` и `/lua status 1`.

**Неизвестное имя маршрута** — файл должен находиться в `scripts/routes` и называться ровно `<имя>.json`.

**Ошибка на точке** — проверьте положение персонажа, транспорт, ограничения по времени и журнал. Смена интерьера или другая карта могут сделать координаты неприменимыми.

**Скрипт стартует, но не работает мини-игра** — эта сборка не добавляет универсальное прохождение всех мини-игр. Нужен подходящий проверенный обработчик.

**Проверка на телефоне** — сборка проверена автоматическими тестами с имитацией сессии. Реального соединения с игровым сервером и проверки на вашем Android не было.

## 12. Sing-box и офлайн-полигон

Отдельная подробная инструкция — `SINGBOX_I_POLIGON.md`. Установите sing-box в Termux: `pkg install sing-box`; в консоли доступны `/singbox status` и `/vpn`. Тестовые Lua лежат в `test_lua_scripts/` и проверяются командой `/luatest run example.lua example_events.json` без подключения аккаунта.
