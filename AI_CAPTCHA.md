# Автокапча через OpenAI SDK

Бот получает адрес изображения из игрового интерфейса 26, скачивает изображение и отправляет его **напрямую выбранному провайдеру** через OpenAI Python SDK. Запрос использует совместимый `POST /chat/completions` с изображением в формате data URL и текстовой инструкцией. Промежуточный сервис RakOCR в цепочке по умолчанию не вызывается. SDK тоже обращается к сетевому API модели; он не запускает модель локально.

## Установка и настройка

```sh
python -m pip install -r requirements.txt
cp .env.example .env
nano .env
```

Заполните три значения в `.env` или переменных окружения:

```dotenv
CAPTCHA_BASE_URL=https://api.openai.com/v1
CAPTCHA_API_TOKEN=ваш_токен
CAPTCHA_MODEL=точный_id_vision_модели
```

Base URL — **базовый адрес API** без `/chat/completions` на конце. Для другого провайдера укажите его Base URL и соответствующие ему ключ и ID модели. Не каждая OpenAI-совместимая модель поддерживает входные изображения или data URL. Требуется HTTPS. Модель и провайдер должны поддерживать Chat Completions с изображениями. Пустые значения отключают распознавание изображений: случайный ответ не отправляется. Значения переменных окружения имеют приоритет над `.env`. Не публикуйте токен; `.env` исключён из Git. После настройки перезапустите программу.

Пример запроса, который формирует SDK: массив `messages`, в нём часть `type: text` с инструкцией и часть `type: image_url` с `url: data:image/png;base64,...`. Это API-запрос к выбранному вами поставщику модели; он может взимать плату и получать изображение капчи. Ответ с лишним текстом, отказ модели, нераспознанный текст и ошибки не отправляются в игру. Текст ошибок провайдера не записывается, чтобы не раскрыть ключ.

## Проверка

```sh
python -m unittest -v test_openai_captcha test_captcha_api test_captcha
```

Тест структуры использует настоящий SDK и подменённый HTTP-транспорт: проверяет конечный путь, авторизацию, ID модели, Base64 и состав сообщения, не обращаясь к провайдеру. Дополнительно проверяются неправильные ответы, отказ, отсутствие ключа, ошибки и передача распознанного текста в интерфейс игры. Это не проверка качества распознавания модели и не проверка настоящего провайдера или игрового сервера. Для них нужны действующие настройки и реальная капча. В игровом журнале ошибки начинаются с `[captcha-ai]`.
