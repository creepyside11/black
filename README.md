# RakCRMP — удобный запуск ботофермы на серверах Black Russia

RakCRMP — программа для управления игровыми ботами из терминала, через Telegram или веб-панель. Она работает как сетевой клиент: графический клиент игры и Android-приложение не запускаются.

[Канал @rakcrmp_br](https://t.me/rakcrmp_br) · [Чат @rakcrmp](https://t.me/rakcrmp) · [Бот @rakcrmprobot](https://t.me/rakcrmprobot)

## Возможности

- Управление аккаунтами и игровыми сессиями из консоли и Telegram.
- Веб-панель для просмотра состояния и отправки команд.
- Lua-загрузчик: дополнения к существующим задачам и самостоятельные сценарии, которые можно запустить до спавна.
- Локальный тестовый полигон для Lua, маршруты, настройки и логи скриптов.
- Опциональное распознавание изображений капчи через OpenAI-совместимый API и модель с поддержкой изображений.
- Опциональный мост sing-box для существующей пользовательской конфигурации.

Работа на конкретном игровом сервере зависит от его протокола, доступных данных и версии клиента. Тестовый полигон имитирует действия и не подтверждает работу игрового сценария на сервере.

## Требования

- Python 3.10 или новее и Git.
- Для Lua-сценариев — отдельно установленный Lua 5.4.
- Для ИИ-капчи — доступ к OpenAI-совместимому сервису, API Token и ID модели, принимающей изображения.
- Для VPN-моста — установленный sing-box и собственная конфигурация.

### Termux на Android

```sh
pkg update
pkg install git python lua -y
git clone https://github.com/creepyside11/black.git
cd black
python -m pip install -r requirements.txt
python bot.py
```

Название пакета Lua зависит от версии Termux: если `lua` недоступен, проверьте `lua54`. Сама программа работает и без Lua, но Lua-скрипты не запустятся до установки интерпретатора.

### Linux / VPS

```sh
sudo apt update
sudo apt install -y git python3 python3-venv lua5.4
git clone https://github.com/creepyside11/black.git
cd black
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python bot.py
```

### macOS

Установите Git, Python 3.10+ и при необходимости Lua 5.4. Затем:

```sh
git clone https://github.com/creepyside11/black.git
cd black
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python bot.py
```

Для Termux, Linux и macOS можно установить команду `br` через `bash install.sh`. Сами Python-зависимости устанавливаются командой `pip` выше.

### Windows

Установите Python 3.10+ и Git, затем выполните в PowerShell:

```powershell
git clone https://github.com/creepyside11/black.git
cd black
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe bot.py
```

Lua и sing-box устанавливаются отдельно. Некоторые возможности зависят от операционной системы; их работу на конкретном устройстве нужно проверить.

## Lua: скрипты и боты

Текстовые Lua-файлы размещаются в `scripts/lua`. В консоли программы:

```text
/lua help
/lua list
/lua addon 1 hello_addon.lua --dry
/lua bot 1 spawn_bot.lua --dry
/lua status 1
/lua stop 1
```

`1` — пример ID аккаунта. Флаг `--dry` позволяет проверить сценарий без выполнения изменяющих действий. В режиме `bot` сценарий отвечает за спавн и поддерживаемые им игровые интерфейсы. Для офлайн-проверки используется папка `test_lua_scripts/`; она отделена от рабочих скриптов.

Подробнее: [руководство по Lua](LUA_GUIDE_RU.md), [инструкция по скриптам и маршрутам](INSTRUKTSIYA_LUA_I_MARSHRUTY.md), [полигон и sing-box](SINGBOX_I_POLIGON.md), [документация для разработки с ИИ](AI_BOT_DEVELOPMENT_RU.md).

## Загрузка и запуск Lua через Telegram

В личном чате с управляющим ботом откройте `/start` → «Lua: загрузить и запустить» → «Загрузить .lua» и отправьте файл документом. Нужен настроенный ID администратора. Принимается текст UTF-8 до 256 КБ с именем из латинских букв, цифр, точек, `_` и `-`; существующий файл не перезаписывается. Загрузка сама по себе скрипт не запускает. Отправляйте только файлы, которым доверяете.

Чтобы запустить файл для существующего аккаунта, откройте его карточку → «Lua» → «Запустить Lua», выберите файл и режим:

- **Дополнение** работает рядом с основной задачей; при конфликте действий остановите основную задачу. Дополнение нужно запускать заново после полной остановки аккаунта.
- **Самостоятельный бот** запускается до подключения и отвечает за спавн и игровые интерфейсы. Сначала остановите аккаунт. Выбранный Lua-файл сохраняется как его задача и поднимается снова при следующем запуске.

В мастере «Массовое создание» на шаге выбора задачи нажмите «Выбрать Lua-бота», выберите загруженный файл и продолжите настройку прокси. Каждый новый аккаунт попробует запустить Lua до подключения. Если Lua 5.4 или файл недоступен, подключение такого аккаунта отменяется, а причина появляется в его логе. «Остановить Lua» останавливает сценарий и отменяет его повторный автозапуск; подключённый аккаунт при этом остаётся в игре. Для остановки аккаунта используйте отдельную кнопку.

Загрузчик поддерживает `.lua`, не `.luac`. Наличие файла, проверка синтаксиса и запуск процесса не гарантируют, что конкретный сценарий работает на игровом сервере.

## ИИ-капча

Скопируйте `.env.example` в `.env` и заполните:

```dotenv
CAPTCHA_BASE_URL=https://example.com/v1
CAPTCHA_API_TOKEN=ваш_ключ
CAPTCHA_MODEL=id_модели
```

Укажите HTTPS Base URL и модель с поддержкой изображений. Переменные окружения имеют приоритет над `.env`. Изображение капчи отправляется выбранному провайдеру; качество распознавания зависит от модели. Подробности — [AI_CAPTCHA.md](AI_CAPTCHA.md).

## Веб-панель

```sh
python3 -m web.server
```

Панель работает отдельным процессом и передаёт команды запущенной программе. Вход и настройка описаны в [RUCHNOE_UPRAVLENIE_WEB.md](RUCHNOE_UPRAVLENIE_WEB.md). Для внешнего доступа настройте защищённое подключение и контроль доступа.

## Аккаунты и настройки

При потере связи программа сохраняет существующую запись аккаунта. После сообщения о блокировке новый аккаунт автоматически не создаётся.

В `accounts.json` находится одна примерная запись с ником `test_test` и пустыми полями сервера и пароля. Программа пропустит её, пока эти поля не заполнены. Сам файл отслеживается Git: не записывайте в него реальные пароли перед коммитом. Для рабочих данных можно задать путь через переменную `BR_ACCOUNTS_FILE`, например `accounts.local.json`; этот файл и `.env` исключены из Git. Храните токены на своём устройстве и сохраняйте резервные копии перед обновлением.

### Массовая проверка SOCKS5

В Telegram откройте «Прокси и VPN» → «Массовая проверка SOCKS5», затем пришлите TXT или список: один публичный IPv4 и порт на строку, например `1.1.1.1:1080` или `socks5://логин:пароль@IP:порт`. Это проверка произвольного списка, не смена прокси на аккаунтах. Максимум 20 000 адресов и 2 МиБ. Отдельная задача возвращает файлы `proxy_tcp.txt` и `proxy_udp.txt`; TCP проверяется передачей данных, UDP — ответом STUN с проверкой транзакции. Отсутствие ответа не доказывает отсутствие UDP, а успех STUN не гарантирует доступ к игре. Файлы могут содержать переданные логины и пароли.

Число параллельных проверок автоматически ограничено (обычно 16 для одного CPU, максимум 64); при необходимости его можно изменить переменной `BR_PROXY_CHECK_WORKERS` в пределах 1–128. Проверка не останавливает ботов и не меняет их подключения, но использует CPU, память и сеть VPS; большой параллелизм может влиять на работающие сессии. Локальные и частные IP-адреса, DNS-имена, HTTP и VPN-ссылки не принимаются.


### Telegram: ресурсы, настройки аккаунта и Lua

В общем списке кнопка «CPU, RAM, диск» показывает системную нагрузку, доступную память и свободное место, не останавливая ботов. Доступен только личному чату администратора. Показания системы могут отличаться от лимитов контейнера.

В карточке аккаунта откройте «Настройки аккаунта». Там можно включить или выключить автоматическое переподключение и автоматический опрос статистики `/mm`, выбрать минимальную задержку повторного входа и период опроса. Настройки сохраняются вместе с аккаунтом. Отключение автопереподключения отменяет ожидающий таймер, но не разрывает текущую сессию; при ручном запуске аккаунт всё равно можно запустить. Если ранее была задана более длинная задержка повторного входа, она не сокращается. Здесь же есть переходы к существующим настройкам задачи, цели, прокси и Lua.

Кнопка «Логи по нику» находит аккаунт; в его Lua-логах доступны фильтр ошибок, поиск текста и выгрузка текущего файла и ротаций (не более 4 МиБ). Существующее хранение Lua-логов привязано к ID аккаунта в программе: при смене состава аккаунтов старые записи с тем же ID могут относиться к другому нику. Лог может содержать данные сценария; доступ к поиску и скачиванию разрешён указанным администраторам в личном чате.

В меню Lua список и выбор файлов разбиты по страницам. При выборе файла в списке управления доступно удаление с подтверждением. Назначенный аккаунту или подключённый к Lua runtime файл удалить нельзя: сначала снимите задачу и остановите Lua. Действие не останавливает игровые аккаунты.

В списке аккаунтов доступна выгрузка TXT в формате `ник:пароль:сервер` для текущего проекта. Файл отправляется только указанному администратору в личный чат и содержит пароли. Двоеточия, обратные косые черты и переводы строк внутри значений экранируются обратной косой чертой. Экспорт не отключает аккаунты.
