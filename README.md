## 🛠 Подробная инструкция по установке

> **Важно: нужен Python 3.10 или новее.** В коде есть `int | None` и
> встроенные генерики — на 3.8/3.9 бот теперь честно скажет об этом
> при старте, а не упадёт с `TypeError` из середины импорта.

### 📱 Вариант 1: Установка в Termux (Android)

1. **Обновите пакеты Termux:**
   ```bash
   pkg update -y && pkg upgrade -y
   ```

2. **Установите Git и Python:**
   ```bash
   pkg install git python -y
   ```

3. **Склонируйте репозиторий проекта:**
   ```bash
   git clone https://github.com/creepyside11/black.git
   cd black
   ```

4. **Поставьте команду `br` (зависимости уже в репозитории):**
   ```bash
   bash install.sh
   ```
   Если хочется свежие версии пакетов поверх вендорных:
   ```bash
   pip install -r requirements.txt
   ```

5. **Готово. Запуск:**
   ```bash
   br
   ```

---

### 💻 Вариант 2: Установка на Linux / VPS (Ubuntu, Debian) / macOS

1. **Обновите систему и установите Python + Git:**
   ```bash
   sudo apt update && sudo apt install -y git python3 python3-pip
   ```

2. **Склонируйте репозиторий:**
   ```bash
   git clone https://github.com/creepyside11/black.git
   cd black
   ```

3. **Проверьте версию Python (нужна 3.10+):**
   ```bash
   python3 --version
   ```

4. **Поставьте команду `br`:**
   ```bash
   bash install.sh
   ```
   Скрипт сам найдёт каталог в `PATH` (`$PREFIX/bin` в Termux,
   `~/.local/bin` или `/usr/local/bin` в Linux) и положит туда
   symlink на `bin/br`. Если `~/.local/bin` ещё нет в `PATH`:
   ```bash
   export PATH="$HOME/.local/bin:$PATH"
   ```

5. **Запуск (любой из вариантов):**
   ```bash
   br
   python3 bot.py
   ```

### 🧩 Если при запуске всё-таки ошибка импорта

| Ошибка | Причина | Лечение |
|---|---|---|
| `ModuleNotFoundError: No module named 'logic.minigames'` (или `br`, `projects`, `logic.menu`) | клон старый: файлы не были закоммичены из-за `*.py` в `.gitignore` | `git pull` — модули теперь в репозитории |
| `TypeError: unsupported operand type(s) for \|` | Python 3.9 и ниже | обновите Python до 3.10+ |
| `ModuleNotFoundError: No module named 'resource'` | Windows | исправлено: `resource` теперь опционален |
| `br: command not found` | каталог установки не в `PATH` | `bash install.sh`, затем `export PATH="$HOME/.local/bin:$PATH"` |
| `No module named 'telebot'` / `requests` | пакеты не подхватились | `pip install -r requirements.txt` |

Одиночный клиент (второй интерфейс) запускается отдельно:
```bash
python3 -m br
```

## ✨ Полный обзор всех функций ботнета

### 🧠 1. Автономный Нейроконтроллер (ИИ Командир)
- **Любые модели LLM**: Поддержка OpenAI (`gpt-4o-mini`, `gpt-4o`), DeepSeek (`deepseek-chat`), Anthropic Claude, Qwen, Ollama, OpenRouter, vLLM.
- **Интерактивная настройка через Telegram**: Изменение `Base URL`, `API Token` и `Model ID` в несколько нажатий прямо из меню бота.
- **Естественный язык**: Командир понимает свободную русскую речь и мгновенно выполняет действия:
  - *"Запусти 10 ботов на сервер Воронеж качать лвл"*
  - *"Останови всех ботов кроме 12 и 15"*
  - *"Раскидай аккаунты по случайным серверам и включи мониторинг"*
  - *"Проверь аккаунты на баны и выдай статистику"*
- **Автономный мониторинг 24/7**: При активации команды `monitor_24_7` ИИ непрерывно сканирует состояние фермы, поднимает упавшие инстансы и переподключает их после рестартов серверов.

---

### 🛡 2. Детект банов и мгновенная автозамена аккаунтов
- **Глубокий анализ причин блокировок**:
  - Распознавание киков и банов античита: `читы`, `постороннее ПО`, `кликеры`, `ботоводство`, `ППВ`, пакет `CONNECTION_BANNED (0x19)`.
  - Отсеивание временных блокировок за частые подключения (15–20 минут) от перманентных банов.
- **Мгновенная автозамена забаненного бота**:
  - Если сервер блокирует бота, система не останавливает ферму, а **автоматически регистрирует нового бота с реалистичным ником на том же сервере**, сохраняет в `accounts.json` и сразу запускает выполнять ту же задачу!
- **Анализ через ИИ**: Подробный отчет с причинами бана и советами отправляется владельцу в Telegram.

### 📈 3. Умная качка LVL (`LevelGrinderTask`)
- **Спавн на реальном городском вокзале**:
  - Метод `_ensure_spawn_in_real_world` гарантирует появление персонажа на открытом спавне с реальными игроками, исключая зависание под текстурами в спектейт-зоне.
- **Человеческая рандомизация простоя**:
  - Минимальное время покоя: **20 секунд**.
  - Максимальное время покоя: **9 минут** (540 секунд, строгий запас до серверного AFK-кика в 15 минут).
  - Точность рандомизации вплоть до миллисекунд (`random.uniform(20.0, 540.0)`).
- **Микро-поведение человека**:
  - Случайные повороты головы и угол камеры.
  - Микро-шаги на 1-2 метра вперед/назад, случайные приседания и прыжки.
  - Детект игроков рядом: если в радиусе 9 метров подходит живой человек, бот замирает и прекращает дергаться.
- **Автоответчик администраторам и игрокам**:
  - Автоматически ловит вопросы в `/pm`, личные сообщения и обращения в общем чате (*"ты тут?"*, *"вы тут?"*, *"бот?"*, *"ку"*).
  - Выдерживает реалистичную человеческую задержку печати (2-4 секунды) и отвечает в чат (`"Да, я тут"`, `"тут я, не афк"`, `"/b тут"`).
- **Бессмертие от голода**: Для аккаунтов 1 уровня поддерживается 100 HP, предотвращая смерть от голода до первого PayDay.
- **Авто-сбор бонусов**: Каждые 30 минут автоматически забирает бесплатные награды из донат-меню и ежедневную рулетку.

### ⛏ 4. Квесты Дяди Славы & Шахта (`QuestMasterTask` → `logic/slava.py`)
- **Полная сюжетная линия новичка**, движок стадий:
  - Автоматический скип заставки и диалогов со Славой на вокзале.
  - Покупка еды в уличном киоске, посадка в автомобиль, поездка в 24/7 за аптечкой.
  - Стайлинг-центр, АЗС, ремкомплект, прием звонков от Дяди Славы.
  - Поездка на шахту, переодевание и мини-игра добычи руды (попадание в зеленую зону).
  - Возврат на вокзал, забор кейса новичка в донате и финальный диалог с получением прав категории B и купона x2.
- **Ходьба и езда**: `Navigator` сам решает пешком или на машине —
  по расстоянию (порог 60 м) и по подсказке стадии. `VehicleRunner`
  ищет машину в стриме, подходит к ней (у `setbotvehicle` лимит 10 м),
  садится, заводит `/en`, по прибытии выходит, если надо зайти внутрь.
- **13 стадий** по тексту цели: знакомство, посадка, еда, аптечка,
  стайлинг, заправка, ремкомплект, дорога на шахту, работа, увольнение,
  возврат, подарок, финал.
- Разбор: [SLAVA_PROTOCOL.md](SLAVA_PROTOCOL.md). Тесты: `test_slava.py` (73).

- Один бот — два проекта. Переключение в Telegram (`🌍 Проект`), в веб-панели

- Вход в игру тоже свой: Black Russia начинается пакетом `b"BR"`, Arizona

  `0x09`→`0x10`).
- Перед первым запуском на Arizona проверь, чем сервер отвечает на самом деле
  — с той машины, где бот играет:

  ```bash
  python3 tools/project_handshake.py arz
  ```

## 🖥 Веб-панель

```bash
python3 -m web.server            # 0.0.0.0:8080
```

Панель — отдельный процесс. Она не открывает второе подключение к
аккаунтам: кладёт команду в очередь, её исполняет живой бот теми же
методами, что и Telegram-контроллер.

- **Выделение пачкой.** Галочка слева от аккаунта, «Все» в шапке —
  выделяет весь отфильтрованный список. Панель действий умеет
  `Запустить`, `Остановить`, `Статистика`, `В мир` и `Удалить` сразу
  для всех выделенных. Пачки уходят в фон: мост не блокируется, пока
  полсотни ботов подключаются.
- **Уровень и опыт.** `lvl 4 · 12/40 · осталось 28` и полоска прогресса.
  Цифры берутся из меню статистики (`/mm`), а не из реестра, поэтому
  показывают реальное состояние аккаунта.
- **В мир.** Принудительно проверить стрим и вывести бота в общий мир.

Вход: логин и пароль печатаются при первом запуске, на диске только хеш.
Забыл — `python3 -m web.server --reset-password`.

## 🌍 Вход в общий мир

Позиция на вокзале ещё не значит, что бот в мире: если клиент не
отправил ответный Spawn, стрим остаётся пустым — ни игроков, ни машин.

При каждом входе бот проходит ту же последовательность, что проверена
вручную (см. [REAL_WORLD_SPAWN.md](REAL_WORLD_SPAWN.md)):

1. ждёт позицию от сервера;
2. один раз завершает Spawn, если сервер его разрешил;
3. ждёт других игроков в стриме — это и есть доказательство мира;
4. если стрим пуст — переходит на вокзал и проверяет снова.

Повторных подтверждений Spawn в цикле нет: именно они раньше выкидывали
сессию кодом 25. Проверка идёт в фоне, вход её не ждёт.
