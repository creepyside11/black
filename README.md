# Black Russia RakSAMP for Termux

Консольный автономный бот-клиент для серверов **Black Russia** без графики GTA, работающий в Termux на Android.

## Возможности
- Прямое сетевое взаимодействие по протоколу RakNet 0.3.7 с шифрованием пакетов Black Russia (`kyretardize`).
- Автоматический поиск и получение актуального IP и порта любого из 90+ серверов Black Russia через API.
- Эмуляция присутствия и предотвращение AFK-кика (`ID_PLAYER_SYNC`).
- Мульти-аккаунт менеджер: одновременный запуск нескольких ботов на разных/одинаковых серверах в одном процессе.
- Специализированные боты на выбор:
  - **Качка LVL (Anti-AFK & EXP Grinder)**: микро-передвижения, сбор PayDay, предотвращение AFK-киков, авто-сбор бесплатных рулеток/наград раз в 30 мин.
  - **Квесты Дяди Славы (Quest Master)**: перехват JSON-интерфейсов квестов (`onQuestTask`), автоматический диалог с NPC (`onNpcDialog`), авто-ходьба по маркерам/чекпоинтам (`OnSetCheckpoint`) и забор наград.
- Интерактивное меню по цифрам для добавления аккаунтов, выбора режима работы и просмотра логов.
- Консоль команд (/task, /chat, /cmd, /dialog, /menu, /list, /logs, /switch, /q).
- Фоновый запуск внутри Termux (через `tmux` или `nohup`).

## Быстрый старт в Termux

### 1. Перейдите в каталог проекта:
```bash
cd ~/blackrussia
```

### 2. Запуск бота:
```bash
python bot.py <сервер> <никнейм> [пароль]
```

#### Примеры:
- По названию сервера:
  ```bash
  python bot.py red Ivan_Smirnov
  ```
- По номеру сервера:
  ```bash
  python bot.py 1 Ivan_Smirnov
  ```
- Сервер Moscow с паролем:
  ```bash
  python bot.py moscow Anton_Kuznetsov 123456
  ```

## Управление через Telegram Bot

В проект встроен контроллер Telegram с удобным интерфейсом (Inline-кнопки, пагинация ботов, просмотр логов, запуск/остановка, смена задач, массовое создание).

### Запуск с Telegram ботом:
```bash
python3 bot.py --tg ВАШ_ТОКЕН_БОТА [--admin ВАШ_ТЕЛЕГРАМ_ID]
```
Либо через переменные окружения:
```bash
export TG_BOT_TOKEN="ВАШ_ТОКЕН"
export TG_ADMIN_ID="ВАШ_ТЕЛЕГРАМ_ID"  # опционально, чтобы ботом управляли только вы
python3 bot.py
```

### Возможности Telegram интерфейса:
- **Пагинация**: просмотр списка всех ботов по страницам с живыми статусами (Онлайн, Остановлен, БАН).
- **Детальная карточка бота**: просмотр ника, сервера, текущей задачи, локации, уровня и статуса.
- **Логи в реальном времени**: просмотр последних 15 строк логов выбранного бота по нажатию одной кнопки.
- **Управление ботом**: запуск, остановка, снятие бана, отправка сообщений и команд в игру (`/mm`, `/time` и т.д.).
- **Смена задач**: переключение задач на лету (LVL АФК, Квесты, Шахта, Завод, Автобусник).
- **Массовое создание ботов**: генерация и запуск пачки ботов одной строкой (`СЕРВЕР КОЛ-ВО ПАРОЛЬ [ЗАДАЧА]`).
- **Глобальные кнопки**: `Запустить всех` / `Остановить всех`.

## Консольные команды бота во время работы:
- `/chat <текст>` или просто `<текст>` — отправить сообщение в игровой чат.
- `/cmd </команда>` — отправить команду на сервер (например, `/cmd /stats` или `/cmd /time`).
- `/dialog <id> <кнопка> <текст>` — отправить ответ на диалоговое окно (кнопка 1 — левая, кнопка 0 — правая).
- `/q` или `exit` — корректный выход и отключение бота.

## Запуск 24/7 в фоновом режиме

Чтобы бот не выключался при сворачивании Termux:
1. Заблокируйте засыпание Termux:
   ```bash
   termux-wake-lock
   ```
2. Установите `tmux`:
   ```bash
   pkg install tmux -y
   ```
3. Запустите сессию:
   ```bash
   tmux new -s brbot
   python bot.py red Ivan_Smirnov
   ```
4. Для выхода из сессии в фоне нажмите комбинацию: `Ctrl + B`, затем отпустите и нажмите `D`.
5. Чтобы снова открыть консоль бота:
   ```bash
   tmux attach -t brbot
   ```
