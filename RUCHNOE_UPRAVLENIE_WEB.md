# Ручное управление RakCRMP через браузер

Это веб-страница к сетевому клиенту `black`, а не APK и не полноценное отображение игрового мира. Открывать её можно на телефоне через Termux или в браузере с компьютера, на котором работают программа и панель.

## Что реализовано

- Добавление аккаунта с вводом ника, пароля и названия поддерживаемого сервера.
- Выбор аккаунта и подключение в ручном режиме до спавна.
- Просмотр входящего игрового чата и отправка текста или игровых команд.
- Выбор одного из ID точек, полученных от сервера в распознанном меню спавна.
- Отображение обычных диалогов, кнопок, поля ввода и номера пункта.
- Отображение известного диалога NPC и кнопок, когда сервер передаёт поддерживаемые ключи.
- Уведомление, если сервер открыл интерфейс капчи или мини-игры: в этой версии ответа на них через панель пока нет.

3D-мир, управление касаниями, универсальная отрисовка всех игровых окон, ручное прохождение капчи и любых мини-игр **не реализованы**. Стандартная сетевая авторизация остаётся в коде клиента. Сценарии Lua и основную задачу нужно остановить до ручного входа; ручной режим берёт под контроль выбор спавна и указанные интерфейсы.

Игровые действия проверены с имитацией сервера, но не на реальном сервере игры или вашем телефоне. Сервер может прислать окно в другом формате.

## Установка в Termux

Скачайте `black_lua_loader.zip` в папку загрузок и введите:

```sh
pkg update
pkg install python lua54 unzip -y
termux-setup-storage
mkdir -p "$HOME/black-manual"
unzip -o "$HOME/storage/downloads/black_lua_loader.zip" -d "$HOME/black-manual"
cd "$HOME/black-manual/black-lua-loader"
python bot.py
```

При первом запуске выберите `0`, если открылось начальное меню. Оставьте программу работающей. Вторая отдельная установка не переносит автоматически аккаунты из старой папки.

Откройте **вторую сессию Termux** и выполните:

```sh
cd "$HOME/black-manual/black-lua-loader"
python -m web.server --host 127.0.0.1 --port 7777
```

При первом запуске сервер панели покажет логин и пароль панели — сохраните их локально. Это отдельные учётные данные, не пароль игры. Если пароль панели уже создавался и утерян, можно выпустить новый командой `python -m web.server --reset-password`. Не отправляйте пароль другим.

На том же телефоне откройте в браузере:

```text
http://127.0.0.1:7777/manual.html
```

После входа добавьте свой игровой аккаунт: сервер указывается по названию, которое поддерживает сборка, например `SURGUT`; ник и пароль — ваши игровые данные. Выберите созданный аккаунт и нажмите «Подключить». Сообщения и поддерживаемые окна появятся после их получения от сервера.

Список аккаунтов и команды работают, пока **оба процесса** запущены: `bot.py` и `web.server`. `7777` — порт веб-панели в этих примерах, а не обязательно порт игрового сервера.

## Доступ с другого устройства

На машине, где запущена программа, можно явно открыть панель на сетевом интерфейсе:

```sh
python -m web.server --host 0.0.0.0 --port 7777
```

Тогда адрес зависит от IP этой машины и доступности порта. Не путайте IP веб-сервера с IP игрового сервера. Авторизация панели обязательна, но HTTP без HTTPS передаёт логин, пароль и игровые данные без шифрования. Для удалённого доступа используйте SSH-туннель или настроенный HTTPS reverse proxy и ограничьте доступ к порту. Не открывайте обычный HTTP с паролями в публичный интернет.

Панель в этой сборке выбирает серверы через существующий список проекта. Произвольное подключение к любому игровому `IP:порт` через этот экран не добавлено.

## Ответы в окнах

В списковом диалоге номер строки задаётся с нуля, согласно реализации клиента. Поле текста заполняйте, только если этого требует диалог. Если сервер обновил окно, старый токен ответа отклоняется. Подтверждение отправки ещё не означает, что сервер принял действие: следите за следующими сообщениями и состоянием.

В ручном режиме стандартная автоматическая обработка соответствующих мини-игр и капчи отключается; если появится неподдерживаемое окно, этот этап нельзя завершить через текущий экран.
