# Сборка Black: Lua-загрузчик и ИИ-автокапча

За основу взят архив `black_lua_loader.zip`, версия от 13 ноября 2026. В него добавлены новая интеграция автокапчи с OpenAI SDK и подробная документация для создания ботов. Пользовательский сценарий шахты Сургут, его записанный маршрут и Lua-пример маршрута удалены. Исходные компоненты шахты, уже присутствовавшие в базе проекта, сохранены для совместимости остальных модулей.

## Содержимое и ограничения

- Lua-загрузчик: добавления и боты, события, команды, маршруты и логи — `LUA_GUIDE_RU.md`, `INSTRUKTSIYA_LUA_I_MARSHRUTY.md`.
- Полигон `test_lua_scripts/` и автозапуск sing-box — `SINGBOX_I_POLIGON.md`.
- Управление через веб — `RUCHNOE_UPRAVLENIE_WEB.md`.
- Фермерская задача сохранена. Работу на игровом сервере в этой сборке заново не проверяли.
- Справочник для создания скриптов — `AI_BOT_DEVELOPMENT_RU.md`. Некоторые общие сведения в нём основаны на прежних записях и могут устареть после изменений игры.
- Новая автокапча — `AI_CAPTCHA.md`; в ней три настройки и инструкция.

## Первый запуск в Termux

Распакуйте архив, перейдите в папку проекта, установите Python и Lua и зависимости. На версиях Termux пакеты Python и Lua называются `python` и `lua`:

```sh
pkg update
pkg install python lua
pip install -r requirements.txt
cp .env.example .env
nano .env
python bot.py
```

В `.env` укажите адрес совместимого API, токен и ID модели с поддержкой изображений. Для транспорта провайдера нужна сеть, а доступность конкретной модели и реальное распознавание тестируются отдельно. Подробнее — `AI_CAPTCHA.md`.

Файл `.env` не включён в архив: укажите свои значения. Никому не отправляйте токен.

## Проверки сборки

Автоматические тесты проверяют, среди прочего, запуск Lua в тестовой среде, маршруты, веб-панель, код sing-box и структуру запроса OpenAI SDK с подставным сетевым транспортом. Они не доказывают работу на конкретном сервере Black Russia, реальную доступность модели или запуск sing-box на вашем устройстве. Используйте Lua 5.4 и проверяйте сценарии на тестовом аккаунте.
